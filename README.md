# NASA-Exoplanet-Archive-Data-Analysis
## Overview
This project covers an analysis of the Planetary Systems database in NASA's Exoplanet Archive.
## Data Sources
The Dataset used is the Planetary Systems Database from NASA's Exoplanet Archive which is included in this repository. Originally obtained from https://exoplanetarchive.ipac.caltech.edu/
## Tools Used
- Python
- Pandas
- Numpy
- Matplotlib
- Jupyter Notebook
## Key Questions
1. What is the most common detection method?
2. How have exoplanet detections changed over time?
3. What are the distributions of discovered exoplanet masses, radii, and orbital periods?
4. How are the masses, radii, and orbital periods of discovered exoplanets related?
5. Do certain detection methods favour certain types of exoplanet?
## Process
- Loading the data into a Pandas DataFrame
- Investigating the data and identifying and handling missing and duplicate values
- Exploratory data analysis to identify trends in the data
- Data visualisation using Matplotlib
## Key Findings
1. The transit method is the most common method for detecting extra-solar planets.
2. Exoplanet detections have increased over time.
3. Discovered exoplanets in the data tend to be more massive, have larger radii, and shorter orbital periods than the Earth.
4. Mass and radius are positively correlated.
5. The transit method favours detecting planets that are close to their host star with short orbital periods. Other detection methods, such as direct imaging, favour detecting large, massive planets that are distant from their host stars.
